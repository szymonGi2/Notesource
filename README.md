# Notesource

A simple, welcoming space to collect your thoughts. **Notesource** is a lightweight note-taking app for keeping ideas, plans, and reminders organized.

## Features

- Create, edit, and delete notes
- Organize notes into Personal, Work, and Important categories
- Search by note title, content, or category
- Combine search with category filters
- Responsive layout with a calm, easy-to-read design

> Notes are currently stored in app state and are reset when the page is refreshed.

## Getting started

Install the dependencies and start the development server:

```bash
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```

## Built with

React, TypeScript, Vite, and Tailwind CSS.
